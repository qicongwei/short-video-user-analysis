# short-video-user-analysis

216 份有效问卷的短视频用户使用习惯分析：从基础画像、内容偏好、用户分群，到成瘾心理与风险预测。

一次完整的问卷数据分析管线——五个分析模块共用一个配置，从原始表格一直走到 HTML 报告与图表。

## 数据

`363517082_按文本_短视频用户调研问卷_218_216.xlsx` 是问卷平台导出的原始表：回收 218 份，有效 216 份，52 列。

**已做脱敏**：导出时删除「来自IP」「来源详情」两列（原表含受访者 IP 与地理归属地），保留的是性别、年龄段、职业、行为选择与各量表得分。

问卷覆盖七类问题：

| 类别 | 内容 |
|---|---|
| 基础属性 | 性别、年龄段、职业身份 |
| 平台与时长 | 常用平台、日均使用时长 |
| 场景与动机 | 使用场景、使用目的、内容偏好、互动行为 |
| 消费与营销 | 直播间停留因素、购买意愿、营销影响感知 |
| 成瘾量表 | Q11–Q18，8 题 Likert 五点计分 |
| 自控力量表 | Q19–Q22，含 2 道反向题 |
| 习得性无助量表 | Q27–Q32 |

## 五个分析模块

| 模块 | 方法 | 产出 |
|---|---|---|
| `module_01_basic_profile.py` | 频数统计 + 饼图 / 柱状图 | 性别、年龄、职业、日均时长分布 |
| `module_02_content_behavior.py` | 多选题拆分编码（按 `┋` 分隔符展开后统计被选次数） | 使用目的、内容偏好、使用场景、互动行为 |
| `module_03_clustering.py` | 特征工程（5 维）→ StandardScaler → 肘部法则定 K → K-Means（K=3）→ 轮廓系数评估 → PCA 降维可视化 | 三类用户群体：轻度理性 / 中度依赖 / 重度成瘾高风险 |
| `module_04_addiction_psychology.py` | Likert 计分（含反向题翻转）+ 分组聚合 + 独立样本 t 检验 | 四大量表对比、时长与成瘾指数关系、性别差异检验 |
| `module_05_decision_tree.py` | 特征工程（剔除量表题避免循环论证）→ 按成瘾指数分位数三分类 → CART 决策树 → 特征重要性 → 混淆矩阵与交叉验证 | 成瘾风险预测规则与关键影响因素 |

## 快速开始

```bash
git clone https://github.com/qicongwei/short-video-user-analysis.git
cd short-video-user-analysis

python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

pip install pandas numpy matplotlib scikit-learn scipy openpyxl

python source_code/module_01_basic_profile.py
python source_code/module_02_content_behavior.py
python source_code/module_03_clustering.py
python source_code/module_04_addiction_psychology.py
python source_code/module_05_decision_tree.py
```

模块按编号顺序执行，图表写入 `charts/`。`config.py` 里统一定义了数据路径、列名映射、Likert 映射、多选分隔符和配色，五个模块都从这里取配置，保证口径一致。

> `charts/` 里已放好一次完整运行的产出（16 张 PNG），不跑代码也能看结果。

## 主要发现

以下数值均取自 `05_分析结论.html` 的实跑结果（N=216）。

1. **群体分层明显**。K-Means（K=3）把 216 人分为三群：52.8% 轻度理性（时长偏短、成瘾指数低，但算法依赖高达 4.08）、23.1% 中度依赖（成瘾中高、自控力尚可）、24.1% 重度成瘾高风险（日均超 3 小时，成瘾指数 3.92、习得性无助 3.91）。
2. **性别差异显著**。独立样本 t 检验 t=-2.306，p=0.022，女性平均成瘾指数 2.90 高于男性 2.58，差值 0.32。美妆 / 穿搭类内容以 75 票居首，可能是该差异的来源之一。
3. **算法依赖普遍偏高**。全体均值 3.62/5，被动接受推荐多于主动搜索；连轻使用时长的群体也达 4.08，信息茧房风险需要单独关注。
4. **成瘾与习得性无助强相关**。重度群体无助指数 3.91，轻度群体 1.79；使用时长越过 2 小时后成瘾指数从 2.31 跃升到 3.49，提示双向强化。
5. **消费行为已深度融合**。36.6%（79 人）把「购买商品」选为最常互动行为，远高于点赞（8 人）与评论（14 人）；睡前场景占 31.5%，与购物冲动时段高度重叠。

## 已知限制

1. **样本为便利抽样**（微信渠道为主），216 份不足以代表全体短视频用户，结论只描述样本内部结构。
2. **自报数据**：使用时长是主观估计的区间选择，不是客观采集。
3. **横断面**：单次问卷无法做因果推断，聚类与决策树都是相关性结构。
4. 决策树在 216 样本上做了交叉验证，但仍存在过拟合风险，仅作可解释性演示。
