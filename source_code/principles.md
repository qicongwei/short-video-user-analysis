## 1. StandardScaler — 数据标准化

### 为什么需要标准化？

在本项目中，我们用于聚类的5个特征量纲各不相同：
- **使用时长**：范围 1~4（离散值）
- **成瘾指数**：范围 1~5（连续均值）
- **自控力**：范围 1~5（连续均值）

如果直接使用原始值进行 K-Means 聚类，**量纲大的特征会主导聚类结果**。例如"成瘾指数"的绝对数值范围比"使用时长"大，会使得聚类更依赖于成瘾指数而忽略使用时长的影响。

### 数学原理

StandardScaler 将每个特征转换为**均值为0、标准差为1**的标准正态分布：

$$z = \frac{x - \mu}{\sigma}$$

其中：
- $x$ 是原始值
- $\mu$ 是该特征的均值
- $\sigma$ 是该特征的标准差
- $z$ 是标准化后的值（Z-score）

### ⭐ 重要知识点

1. **标准化 ≠ 归一化**：标准化（Z-score）不改变分布形状，只改变均值和方差；归一化（Min-Max）将数据压缩到 [0,1] 区间
2. **必须用训练集的 μ 和 σ**：如果先对全体数据 fit，再 split，会导致**数据泄露**（data leakage）
3. **标准化后均值为0不代表所有值为0**，只是整体分布中心在0点

## 2. K-Means 聚类算法

### 核心思想

K-Means 是一种**无监督学习**算法，目标是将 N 个样本划分到 K 个簇中，使得**簇内样本尽可能相似，簇间样本尽可能不同**。

### 算法步骤

```
1. 随机选择 K 个点作为初始聚类中心（centroids）
2. 重复以下步骤直到收敛：
   a. 【分配步骤】计算每个样本到 K 个中心的距离，将样本分配给最近的中心
   b. 【更新步骤】重新计算每个簇的均值，作为新的聚类中心
3. 当聚类中心不再变化（或变化极小）时停止
```

### 数学表达

目标是最小化**簇内平方和（Inertia / WCSS）**：

$$\text{Inertia} = \sum_{i=1}^{K} \sum_{x \in C_i} ||x - \mu_i||^2$$

其中 $C_i$ 是第 i 个簇，$\mu_i$ 是第 i 个簇的中心。

### ⭐ 重要知识点

1. **K 值选择是关键**：K 太小则欠拟合（不同群体被合并），K 太大则过拟合（同一群体被拆分）
2. **对初始中心敏感**：不同的初始中心可能收敛到不同的局部最优解（使用 `n_init=10` 多次运行取最优）
3. **只适用于球形簇**：K-Means 假设簇是球形的（各方向方差相同），对非球形数据效果差
4. **对异常值敏感**：异常值会拉偏聚类中心

### 本项目中的应用

选择 K=3，将216名用户划分为：
- **群体A（轻度理性）**：114人（52.8%）
- **群体B（中度依赖）**：50人（23.1%）
- **群体C（重度成瘾高风险）**：52人（24.1%）

## 3. PCA 主成分分析

### 为什么需要 PCA？

我们有5个特征维度，无法直接在二维平面上可视化聚类结果。PCA 将高维数据**投影到低维空间**，同时尽可能保留原始数据的方差信息。

### 核心思想

PCA 寻找数据中**方差最大**的方向（主成分），将数据投影到这些方向上。

### 数学原理

1. **计算协方差矩阵**：描述各特征之间的线性相关性
2. **特征值分解**：找到协方差矩阵的特征向量和特征值
   - 特征向量 = 主成分方向
   - 特征值 = 该方向上的方差大小
3. **选择前 k 个最大特征值对应的特征向量**，构成投影矩阵
4. **将原始数据乘以投影矩阵**，得到降维后的数据

### 解释方差比

$$\text{解释方差比}_i = \frac{\lambda_i}{\sum_{j=1}^{d} \lambda_j}$$

表示第 i 个主成分解释了原始数据总方差的百分比。

### ⭐ 重要知识点

1. **PCA 是线性变换**，只能捕捉线性关系，对非线性结构效果有限
2. **必须先标准化**，否则量纲大的特征会主导主成分方向
3. **累计解释方差比 > 80%** 通常认为降维效果良好
4. **主成分不可解释**：每个主成分是原始特征的线性组合，可能没有直观的物理含义
5. **PCA vs t-SNE**：PCA 保留全局结构，适合可视化聚类；t-SNE 保留局部结构，适合可视化高维数据的邻域关系

### 本项目中的应用

- PC1 解释了 **70.0%** 的方差
- PC2 解释了 **13.2%** 的方差
- 累计 **83.2%**，说明二维投影保留了原始数据的大部分信息

## 4. 独立样本 t 检验

### 什么时候用？

用于比较**两组独立样本**的均值是否存在**统计学显著差异**。

在本项目中：比较**男性**和**女性**的成瘾指数均值是否不同。

### 假设检验框架

| 假设 | 含义 |
|------|------|
| **H₀（零假设）** | 两组均值相等：μ_男 = μ_女 |
| **H₁（备择假设）** | 两组均值不相等：μ_男 ≠ μ_女 |

### p 值解释

- **p < 0.05**：如果零假设成立，观察到当前差异的概率小于5% → **拒绝零假设**，认为差异显著
- **p ≥ 0.05**：不能拒绝零假设，差异可能是随机波动导致的

### ⭐ 重要知识点

1. **p < 0.05 不代表"差异很大"**，只代表"差异不太可能是偶然的"
2. **样本量影响 p 值**：大样本下微小的差异也可能显著
3. **t 检验的前提假设**：
   - 两组数据相互独立
   - 数据近似服从正态分布（大样本时可放宽）
   - 两组方差相等（Welch's t-test 可放宽此假设）
4. **p-hacking 问题**：不要对同一数据反复做多种检验后只报告显著的结果

### 本项目中的应用

- 男性成瘾均值：2.58
- 女性成瘾均值：2.90
- t = -2.306，**p = 0.022 < 0.05**
- 结论：**女性用户的短视频成瘾倾向显著高于男性**

## 5. 多选题拆分编码

### 问题描述

问卷中的多选题数据存储格式为：
```
A.休闲娱乐┋B.发布创作内容┋C.社交互动续火花┋D.获取资讯、知识
```

一个单元格包含多个选项，用 `┋` 分隔。统计分析时需要知道**每个选项被选中的总人次**。

### 处理步骤

```python
1. 遍历每行数据
2. 按分隔符 '┋' 拆分字符串
3. 将所有拆分后的选项收集到一个列表中
4. 使用 value_counts() 统计每个选项的出现次数
```

### ⭐ 重要知识点

1. **总人次数 > 样本量**：因为一人可多选，所以百分比之和可能超过100%
2. **分隔符处理**：不同问卷可能使用不同的分隔符（`┋`、`、`、`|`、`;`等），需先检查数据
3. **空值处理**：拆分前需过滤掉 NaN 值

## 6. Likert 量表计分法

### 什么是 Likert 量表？

Likert 量表是一种常用的态度测量工具，受访者对一系列陈述表达同意程度，通常分为5级或7级。

### 本项目的计分规则

| 选项 | 数值 |
|------|------|
| 很不符合 | 1 |
| 不符合 | 2 |
| 一般 | 3 |
| 符合 | 4 |
| 很符合 | 5 |

### 量表指数构建

每个心理维度由多道题目组成，取各题得分的**算术平均**作为该维度的指数：

$$\text{维度指数} = \frac{1}{n} \sum_{i=1}^{n} \text{题目}_i$$

### 反向题处理

某些题目的措辞方向与其他题目相反。例如：
- 正向题："我能很好地抵制诱惑" → 高分 = 自控力强
- 反向题："有时忍不住做明知不对的事" → 高分 = 自控力弱

反向题需要**反转计分**：新得分 = 6 - 原得分（5点量表）

### ⭐ 重要知识点

1. **Likert 数据是定序数据（ordinal）而非定距数据（interval）**，严格来说不能直接算均值。但在社会科学研究中，通常假定等距以简化分析
2. **Cronbach's α 系数**：用于检验量表内部一致性，α > 0.7 表示信度良好
3. **均值比较时注意极端值**：少数极端回答可能拉偏均值

## 7. 肘部法则（Elbow Method）

### 用途

帮助确定 K-Means 聚类的最佳 K 值。

### 原理

1. 分别计算 K=1, 2, 3, ..., 10 时的 Inertia（簇内平方和）
2. 绘制 Inertia vs K 的曲线
3. 找到曲线的**拐点**（elbow point）—— 即 Inertia 下降速度明显减缓的位置

### 为什么叫"肘部法则"？

曲线的形状类似人的手臂：从肩膀到肘部下降很快，肘部之后趋于平缓。肘部位置对应的 K 就是最佳聚类数。

### ⭐ 重要知识点

1. **肘部不总是清晰的**：如果曲线平滑下降没有明显拐点，肘部法则可能失效
2. **替代方法**：轮廓系数（Silhouette Score）、Gap Statistics
3. **领域知识优先**：统计方法只是参考，最终 K 值应结合业务理解确定
