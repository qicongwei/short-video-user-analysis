⭐ 核心技术：多选题拆分编码 —— 将 "A.选项1┋B.选项2" 按分隔符拆开，统计每个独立选项被选中的总人次 
def expand_multi_choice(series, sep='┋'):
    """多选题拆分编码"""
    all_choices = []
    for val in series.dropna():
        parts = str(val).split(sep)
        all_choices.extend([p.strip() for p in parts if p.strip()])
    return pd.Series(all_choices).value_counts()

# 使用

StandardScaler — 数据标准化

为什么需要标准化？

K-Means 基于欧氏距离计算相似度。如果各特征量纲不同（如"使用时长"1-4 vs "成瘾指数"1-5），量纲大的特征会主导聚类结果。

数学公式

z = (x - μ) / σ
将每个特征转换为均值=0、标准差=1 的标准正态分布。μ 为均值，σ 为标准差，z 为 Z-score。

⭐ 重要知识点

1. 标准化 ≠ 归一化（Min-Max）
2. 必须用训练集的 μ 和 σ，避免数据泄露
3. 标准化后均值为0不代表所有值为0
②
K-Means 聚类算法

核心思想

无监督学习，将 N 个样本划分到 K 个簇，使簇内相似、簇间不同。最小化簇内平方和（Inertia）。

算法步骤

1. 随机选 K 个初始中心
2. 分配：每个样本归入最近中心
3. 更新：重新计算各簇均值作为新中心
4. 重复 2-3 直到收敛

⭐ 重要知识点

1. K 值由肘部法则确定
2. 对初始中心敏感（n_init=10 多次运行）
3. 只适用于球形簇
4. 对异常值敏感
本项目结果：K=3，群体A（轻度理性）114人 | 群体B（中度依赖）50人 | 群体C（重度成瘾高风险）52人
③
PCA — 主成分分析降维

为什么需要 PCA？

5维特征无法直接在二维平面可视化。PCA 将高维数据投影到低维空间，同时尽可能保留方差信息。

数学原理

1. 计算协方差矩阵
2. 特征值分解 → 特征向量=主成分方向
3. 选择前 k 个最大特征值对应的方向
4. 投影原始数据

⭐ 重要知识点

1. 线性变换，只能捕捉线性关系
2. 必须先标准化
3. 累计方差 > 80% 表示降维效果好
4. PCA 保留全局结构，t-SNE 保留局部结构
本项目结果：PC1 解释 70.0% 方差，PC2 解释 13.2%，累计 83.2%
④
独立样本 t 检验

什么时候用？

比较两组独立样本的均值是否存在统计学显著差异。本项目用于比较男性和女性的成瘾指数。

假设检验框架

H₀：μ_男 = μ_女（两组均值相等）
H₁：μ_男 ≠ μ_女（两组均值不相等）
p < 0.05 → 拒绝 H₀，差异显著

⭐ 重要知识点

1. p < 0.05 ≠ 差异很大，只表示非偶然
2. 大样本下微小差异也可能显著
3. 前提：独立、近似正态、方差齐性
4. 避免 p-hacking
本项目结果：男 2.58 vs 女 2.90，t=-2.306，p=0.022 < 0.05 → 女性成瘾倾向显著高于男性
⑤
多选题拆分编码

问题

多选题数据以 "A.选项1┋B.选项2" 格式存储在一个单元格中，需拆分为独立选项进行统计。

处理方法

1. 遍历每行，按分隔符拆分
2. 收集所有选项到列表
3. value_counts() 统计频次

⭐ 注意

1. 总人次 > 样本量（一人多选）
2. 不同问卷分隔符可能不同
3. 需过滤 NaN 值
